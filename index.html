☁️ Cloud Hosting & Tunnel Guide
Host this web dashboard in the cloud (GitHub Pages, Vercel, Netlify) so anyone can access it from their phone or laptop anywhere in the world!
Option 1: Deploy to Vercel (1-Click Free Hosting)
Install Vercel CLI and run inside Smart_Assistant_Web:
npx vercel --prod
Option 2: GitHub Pages (100% Free Forever)
Push the Smart_Assistant_Web folder to GitHub and enable Settings > Pages > Deploy from Branch (main).
Option 3: ngrok Secure Tunnel (Worldwide Access to ESP32)
If your website is hosted on HTTPS, forward your ESP32 IP with free ngrok:
ngrok http 192.168.1.105:80
Then paste the https://xxxx.ngrok-free.app URL into the top connection bar!
