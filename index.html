cloud Cloud Hosting & Tunnel Guide
Host this web dashboard in the cloud (GitHub Pages, Vercel, Netlify) so anyone can access it from their phone or laptop anywhere in the world!
cloud Option 1: Deploy with Cloudflare Pages (Recommended)
Deploy instantly via Wrangler CLI with 1 command (unlimited global edge hosting):
npx wrangler pages deploy . --project-name=esp32-assistant
Or drag-and-drop the Smart_Assistant_Web folder in the Cloudflare Dashboard > Workers & Pages > Create > Pages > Upload assets.
vpn_lock Option 2: Cloudflare Tunnel (Free Worldwide ESP32 Access)
Forward your local ESP32 IP securely with Cloudflare Quick Tunnel:
cloudflared tunnel --url http://192.168.1.105:80
Copy the generated https://xxxx.trycloudflare.com URL into the top connection bar!
public Option 3: GitHub Pages & Vercel
Deploy via npx vercel --prod or enable GitHub Pages in your repository settings under Settings > Pages.
